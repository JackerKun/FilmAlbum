# Film Album

Film Album 是一个本地优先的数字暗房和胶卷档案工作台。它以真实胶卷的浏览方式组织照片和视频，并提供接触印样、逐格显影、智能选片和完整项目备份。

## 运行

```bash
npm run serve
```

浏览器访问 `http://localhost:8091`。无需安装运行依赖。

## 工作模式

- **胶卷**：真实 135 片头、连续齿孔、暗盒出口和逐格浏览。
- **照片索引**：缩略图尺寸、筛选、Command/Ctrl 多选、Shift 范围选择、星级与批量处理。
- **大图查看**：滚轮缩放、拖拽平移、逐张切换、原片对比与当前帧导出。
- **沉浸翻阅器**：在胶卷中点击已选照片或双击任意照片，底部展开整卷缩略图并可直接跳转。

## 主要功能

- 照片与视频混排，多胶卷档案管理。
- 135 与 120 常见画幅、拍摄状态、相机、镜头、地点和冲洗记录。
- 29 种 Kodak、Fujifilm、CineStill、Ilford、Lomography 胶卷风格，并按彩色、反转、黑白、电影分类。
- 曝光、对比度、饱和度、色温、褪色、颗粒、高光晕染和暗角。
- 参数复制、粘贴及同步到所选照片。
- 本地画质分析：亮度、反差、清晰度与相似画面检测。
- 撤销、重做及键盘方向键浏览。
- 完整 `.filmalbum` 项目导入导出，包含媒体、档案与编辑参数。
- IndexedDB 本地媒体存储；默认不上传任何照片。
- 桌面、平板和手机响应式界面。

## 快捷键

- `1`：胶片视图
- `2`：接触印样
- `3`：显影视图
- `←` / `→`：上一格 / 下一格
- `Command/Ctrl + Z`：撤销
- `Command/Ctrl + Shift + Z`：重做

## 数据安全

浏览器缓存或网站数据被清理时，IndexedDB 中的媒体也可能被删除。重要项目请通过顶部“项目 → 导出完整项目”保存 `.filmalbum` 文件；重新导入即可恢复全部媒体和编辑记录。
