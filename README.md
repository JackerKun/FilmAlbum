# Film Album

Film Album 是一个本地优先的胶卷照片管理工作台。它以真实胶卷的浏览方式组织照片和视频，专注于整卷归档、照片索引、星级收藏、EXIF 查看和沉浸式翻阅。

## 运行

```bash
npm run serve
```

浏览器访问 `http://localhost:8091`。无需安装运行依赖。

## 工作模式

- **胶卷**：真实 135 片头、连续齿孔、暗盒出口和逐格浏览。
- **照片索引**：缩略图尺寸、评分筛选、Command/Ctrl 多选与 Shift 范围选择。
- **沉浸翻阅器**：在胶卷或照片索引中双击任意照片，支持滚轮缩放、拖拽平移、逐张切换、星级评分和底部整卷缩略图跳转。

## 主要功能

- 照片与视频混排，多胶卷档案管理。
- 135 与 120 常见画幅、拍摄状态、相机、镜头、地点和冲洗记录。
- 创建胶卷时可按彩色负片、反转片、黑白与电影胶片筛选型号；型号只用于胶卷档案与真实包装色系，不修改原始照片。
- 自动读取 JPEG EXIF，包括相机、镜头、时间、尺寸、焦距、光圈、快门和 ISO。
- 一至五星评分，并可在照片索引中筛选精选或未评分照片。
- 撤销、重做及键盘方向键浏览。
- 完整 `.filmalbum` 项目导入导出，包含媒体、档案与编辑参数。
- 项目根目录 `data/library.json` 保存目录，`data/media/` 保存原始媒体；默认不上传任何照片。
- 桌面、平板和手机响应式界面。

## 快捷键

- `1`：胶片视图
- `2`：照片索引
- `←` / `→`：上一格 / 下一格
- `Command/Ctrl + Z`：撤销
- `Command/Ctrl + Shift + Z`：重做

## 数据安全

照片和目录直接保存在项目根目录 `data/` 中，清理浏览器缓存不会影响资料库。`data/` 默认被 Git 忽略；迁移或备份时请完整复制该目录，也可以通过“项目 → 导出完整项目”生成 `.filmalbum` 备份。
