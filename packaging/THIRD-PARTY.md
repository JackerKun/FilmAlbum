# Bundled components

The desktop app includes Electron / Chromium / Node.js (their license files accompany the runtime), sharp and libvips, exifr, pdf-lib, fontkit, jsQR and Tesseract.js. Their respective license files are retained inside node_modules.

Noto Sans SC is distributed under the SIL Open Font License. See assets/fonts/OFL.txt. Tesseract fast language data is distributed under Apache-2.0; the source URLs and SHA-256 hashes are recorded in scripts/asset-sources.json.

The application logo was generated for this project with the built-in imagegen tool. See assets/LOGO.md for its prompt and provenance.
