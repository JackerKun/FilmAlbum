# Film Album Studio 开发进度

## 3.0.1 · 桌面保存、离线预览与目录整理

- 前端、服务端、共享代码归入 src/；旧界面放入 client/legacy，测试、Swift 和公开资源分别归位。
- 桌面通过受限 preload 连接系统保存对话框；原片和 PDF 使用带会话认证的流式保存、临时文件及完成反馈。
- 原片提供规范附件文件名，PDF 支持 HEAD / GET；生成与保存状态分别呈现。
- 离线预览同时生成 640 / 1600 缓存，统计成功 / 失败 / 跳过，补齐旧引用导入中的缺失预览；离线可使用较大缓存回退。
- 离线筛选空状态、缓存总览、原生目录选择、引用导入和失败重试有明确入口。
- 增加真实文件保存、离线断盘与结构检查；桌面启动自检经实际 preload 保存原片和画册 PDF。

## 边界与下一阶段

- macOS 与 Windows 已有桌面打包；Windows 的格式与分类能力边界见上方 3.0 说明。
- 分类 / OCR / 词表辅助检索已实现，任意自然语言视觉理解和向量检索未实现。
- 单次批量最多 10,000 条，画布最多 2,000 张。它们是明确资源边界，不会一次加载全库。
- 已有自由画册排版及出血 PDF；尚无 CMYK / PDF-X 认证或云协作。
- 目录主存储已升级，旧 JSON 不再持续同步；旧页面会被版本检查阻止覆盖新数据。
- 原片检查第一次建立哈希时无法判断此前已发生的损坏；没有历史基准的文件会明确显示这一状态。
- 容量测试只覆盖模拟元数据查询，不等同于真实海量导入、硬盘故障或 NAS 长时间压力测试。

验证方式、操作入口与数据目录说明见 README.md。
