# 使用指南与功能记录

## 桌面保存文件与离线看片（3.0.1）

- **画册 PDF**：点击“导出打印 PDF”后，等待生成；完成时弹出系统保存窗口。选好位置，保存成功才提示“已保存”。取消后可在任务中心点“保存 PDF”再次保存，不需要重排画册。
- **原片**：右侧“导出原片…”会提示保存位置，保留原始文件名 / 扩展名；不会把离线 JPEG 缓存冒充原片。保存失败或取消不会覆盖原来已有的文件。
- **离线预览**：不是下载包或新资料库。它保存在当前资料库的 previews/ 中，在线时生成 640 / 1600 像素 JPEG；视频不生成静态离线预览。
- **怎么开始**：连接外置盘 → “资料库 → 登记外部存储” → 选择照片文件夹 → 保持“登记后立即引用导入，并缓存离线预览” → 等待任务完成。也可给已导入的原片点击“生成或补齐预览”。
- **拔盘后怎么看**：仍在“全库照片”浏览；“离线 / 断链”只筛选原片暂时不在线的照片。原片都在线时没有结果是正常的，不应重新导入。
- **为什么没图片**：断盘前没有缓存的影像无法离线显示，需要接回原片再生成。任务中心会列出具体失败项目，不再把处理过的数量当作成功数量。
- **需要打印或下载原片**：重新连接原片，挂载位置变了可在对应存储卷点击“重新连接”，然后检查原片。缓存仅供浏览 / 选片。

面向长期胶片收藏的本地档案工作台。原片、底片记录、扫描版本、实物位置和摄影项目分别管理；浏览器每次只加载当前一页。

## 整卷整理与选片

在档案馆的「全部胶卷」切换到「胶片条」，各卷默认展开，滚到附近时载入底片。卡片、胶卷架、表格、时间轴和胶片条都以 50 卷为一批，向下滚动继续加载。新建胶卷或在档案侧栏编辑地点时，可搜索地名或在地图点选，地名与坐标一起保存。点击「打开整卷」进入灯箱，可在顶部导出带格号与卷二维码的接触印样 PDF。PDF 会显示相邻数字格号之间的缺格，带字母的边码会原样保留。

装入扫描件时，先在预演里确认卷、格号和顺序。装入已有胶卷时，可让某张扫描件成为既有底片的重扫版本。使用「核对本页重复文件」可在导入前按内容查重。只有确认文件 EXIF 日期就是拍摄日期时才勾选对应选项。

在看片台可以筛选未评选或已选照片，按 Z 载入原像素。回忆地图可按卷或按照片浏览，照片位置可在右侧档案中设置。项目里的定稿可以生成接触印样或新建画册。

## 启动

需要 Node.js 22.13+（建议 24 LTS）。先执行 `npm ci` 安装依赖。桌面版使用 `npm run desktop`，跨平台打包见 [BUILDING.md](../BUILDING.md)。

```sh
npm run serve
```

打开 http://127.0.0.1:8091 。升级后请先在运行旧服务的终端按 Ctrl-C，再重新启动，然后刷新页面。已有服务占用端口时会显示明确提示；需要并行资料库可以指定：

```sh
PORT=8092 FILMALBUM_DATA_DIR=/绝对路径/另一个资料库 npm run serve
```

macOS 的 EXIF、TIFF/HEIC 预览、二维码识别、PDF 和本地识图使用系统 ImageIO / Vision。首次使用会调用 `xcrun swiftc` 编译随项目提供的 `Native.swift`，需要已安装 Xcode Command Line Tools。本机首次冷编译约 70 秒，期间影像预览可能稍后出现；后续复用缓存。生成的程序保存在资料库 `runtime/`。JPEG 等浏览器原生格式可回退到原图。已打包的 Mac 桌面版内置编译后的辅助程序，不需要用户安装 Xcode；Windows 使用跨平台影像 / OCR / PDF 引擎，具体格式边界见 BUILDING.md。

## 六个工作区

| 工作区      | 功能与入口                                                                                             |

| 看片台      | 全库照片、灯箱、胶片条、摄影年鉴；评分、色标、淘汰；组合 AND/OR 筛选；手动收藏与智能集合               |
| 项目 / 策展 | 项目章节、候选与定稿、拖动排序、自由画布移动缩放、自动排版；导出定稿 PDF                               |
| 定制画册    | 多规格预设、素材组合筛选、毫米排版、四角缩放与拖动裁切、打印 PDF                                       |
| 回忆地图    | 在线县城 / 街道底图，默认中国全国；按视野聚合，选卷照片预览、落点确认和地名查找                        |
| 资料库      | **总览 → 检查原片**；断链、离线、哈希变化、完全重复文件、未归档文件；外部存储、备份、历史与回收站      |

选中胶卷后，右侧“底片位置”保存柜、盒、册、页、片袋和永久编号二维码；可以打印标签，也可以通过命令面板或实物位置面板上传二维码图片识别胶卷。二维码内容是稳定编号，不依赖端口和当前文件路径。

## 导入和原片

- 顶部“导入影像”支持多文件、整个文件夹和拖放文件夹；文件夹分卷或单卷，模板、边码编号和重复策略可选。
- 每批最多 10,000 个文件，单文件最多 1 GB；按 8 MB 片段传输，并核对来源与服务端完整 SHA-256。暂停或关闭浏览器后，可在后台任务重新选择同一批来源继续。来源文件不会被移动。
- 同一格底片可以加入多个扫描或调色版本。右侧“扫描版本”中选择主版本、命名和双图擦拭对照；评分仍属于底片记录。
- 外部移动盘 / NAS 先在“资料库 → 登记外部存储”登记具体照片目录，再“引用导入”。支持可选目录监听。引用不复制或移动源文件；生成离线预览后，盘离线仍可看片。重新连接时选择新的挂载目录并检查原片。
- 发现原片哈希变化会保留原始校验值并标为内容变化，备份也会报告缺失，不能静默当作完好原片。未知哈希的旧文件在首次检查时建立基准。

## 选片与检索

双击照片进入沉浸看片；选两张或四张后按 C 对比。支持同步 / 独立缩放和平移、锁定参考、连续保留换片、保存本轮精选；跨结果页会按需继续加载。

快捷键：⌘K / Ctrl-K 命令与全库搜索，1 / 2 切工作区；看片时 F 适合、Z 原像素、I 展开信息栏（EXIF、RGB 直方图和拍摄位置）、X 淘汰、0–5 评分、方向键换片、Tab 切换对比目标。TIFF 原像素以系统解码的全尺寸 JPEG 显示；离线缓存不冒充原片像素。直方图取显示影像的缩小样本，不是 RAW 测量工具。

“本地识图与 OCR”是可选任务：Apple Vision 分类、文字识别和简单主色线索保存在独立分析字段，不覆盖人工标签。组合筛选启用“语义线索”后，以分类词、OCR 和固定中英文词表辅助查找；**没有接入大语言视觉模型或向量语义检索**。可在照片 EXIF 面板查看分析线索和置信度。所有分析在本机完成。

纸张白、灯箱灰、暗房黑三种主题；拖动侧栏分隔线调宽度，按工作区保存视图、密度与布局。

## 数据与迁移

主目录默认 `data/`（可用 `FILMALBUM_DATA_DIR` 指定）。首次启动从 `library.json` 一次性迁移到 `catalog.sqlite`，并保留 `library.before-studio-时间戳.json`。迁移保留旧文件及原片，之后以 SQLite 为主；不要继续手工修改旧 JSON，也不要在旧页面编辑新目录。`legacy.html` 只用于兼容检查。

- `catalog.sqlite` 及其 WAL：档案、版本、存储卷、倒排词表、收藏、项目、历史。
- `media/`：托管原片；外部引用文件仍在登记的存储卷。
- `previews/`：可重建的离线 JPEG 缓存。
- `tasks.sqlite`：独立任务队列，主目录异常时仍可操作备份恢复。
- `session.json`：当前打开的资料库。切库不会搬动原目录。
- `backups/objects/`：按 SHA-256 复用的原片对象；`snapshots/`：每次独立数据库和清单。

批量修改先预览匹配数量，再检查目录版本；逐条修改检查记录版本，避免覆盖其他窗口的更新。最近 100 次有历史的操作保留压缩快照，界面显示最近 50 条；支持撤销 / 重做，包括照片导入、扫描版本加入和项目布局。过期历史不能替代备份。

删除先进入回收站；收藏和项目可单独恢复，胶卷和照片可批量恢复。永久清空才删除已被回收且不再被任何版本使用的托管原片。未归档文件不自动删除，外部源文件不删除。

## 备份与恢复

在“资料库 → 备份”指定本地、外置盘或已挂载 NAS 目录。备份使用 SQLite 一致性快照，复制时计算哈希，复用的对象也会校验。缺失或发生变化的原片会明确列为不完整快照。

恢复先校验数据库和每个对象，再显示卷数、照片数、缺少原片数，最终写入**新的空文件夹**。支持中断后重试自己的未完成恢复；不会覆盖当前资料库或其他非空目录。恢复后可选择打开新资料库。自动备份仅在服务运行期间检查到期，默认关闭。

备份不包含可重建预览、旧版派生索引、运行时编译缓存和任务历史。外部引用原片在备份时一并收录，恢复后成为新资料库的托管原片。

## Studio 2.1：抽拉、画册和演示模式

**实体胶卷交互已恢复**：在档案馆双击一卷，默认进入带 135 片筒 / 120 卷轴的抽拉视图。拖动金色片头或使用抽拉滑块，支持完全展开、收卷、横向拖动、滚动；单击底片查看档案，双击看片。偏好保存在当前浏览器会话。

**演示 / 调试模式**：仅访问 `http://127.0.0.1:8091/?debug=1` 后显示实验入口 → 生成全新演示资料库 → 后台任务中“打开演示资料库”。包含 8 卷、98 张可见模拟照片、世界坐标、多扫描版本、重复文件、离线预览、断链、回收站、收藏、项目和可编辑示范画册。影像为本地生成的合成图，明确标记。正式目录不会被测试档案覆盖；在 `?debug=1` 页面点击“演示模式 · 返回” → 返回正式资料库。默认菜单不显示调试入口。重新生成会新建独立测试目录，旧演示目录保留。首次编译与生成影像需要等待后台完成。

**地图使用**：打开“回忆地图” → “定位选中胶卷” → 搜索并选择胶卷 → 点击地图落点 → 确认保存。不需要先在另一个工作区保留选择。也可在胶卷右侧“记录”手工输入经纬度。滚轮缩放、拖动平移、聚合点放大、单卷标记打开档案；年份、胶片与文字筛选会作用于地图。地点名称不自动联网转坐标。界面内有“地图使用指南”。

**定制摄影画册**：顶部“定制画册”，新建或打开示范画册。支持 A4、A5、方形、横版及 80–450 mm 自定义尺寸；调整尺寸按比例缩放已有元素。每册最多 200 页，每页最多 100 个元素。

- 空白、满版、双图、四宫格、图文模板；点击或拖入照片，空模板框优先填充。选中已有照片框时点击素材替换照片。
- 毫米精确位置和尺寸，拖动、缩放、旋转、图层、复制、文字字号 / 颜色 / 对齐、照片完整显示 / 铺满和裁切中心。
- 页面增加、复制、删除、前后移动；安全边距与背景色；页面缩放；撤销 / 重做；变更后自动保存，版本锁阻止其他窗口覆盖。
- “打印检查 / PDF”检查缺图、离线和有效 DPI；存在缺失或离线原片时拒绝打印导出。导出使用全尺寸影像，不使用灯箱小缩略图。
- 输出包含 TrimBox、BleedBox、出血和裁切标记的 RGB 单页顺序 PDF。它不是 PDF/X、CMYK 打样或印厂拼版文件；封面书脊厚度、纸张 ICC、装订和专色仍需按具体印厂要求处理。

新增简体中文 / English 切换：主要导航和常用控件使用字典，画册设计器支持双语。仍有动态说明、故障信息与部分旧对话框未完成英文覆盖，不能称为全量国际化。照片和画册内容由用户自行编写，不应自动翻译。

新增 3 项画册自动测试；合计 27 项。另已实际验证演示资料库的生成 / 切换 / 返回、8 个地图坐标、6 页示范 PDF 的页面框及视觉排版。PDF 页面框实现依据 Apple Core Graphics 文档：
https://developer.apple.com/documentation/coregraphics/kcgpdfcontextmediabox

## Studio 2.2：按规格浏览、县城地图与精确排版

- **135 / 120 分离**：135 是带双排齿孔的胶片从暗盒抽出；120 是无齿孔宽胶片、背纸、供片轴与收片轴，卷片时轴头转动，底片物理比例随 6×4.5、6×6、6×7、6×9、6×12、6×17 改变。120 的复位只是界面演示，不代表实物胶卷能够像 135 一样回片。
- **地图**：默认中国全国，加入真正的在线详细瓦片底图，可以缩放至县城和街道。选卷列表显示封面；地图内显示该卷最多 8 张照片的预览。点击落点后还要确认坐标和地点文字，才会保存。地名结果不会自动修改胶卷位置。
- **默认国家 / 全球**：资料库 → 设置 → 地图默认区域。提供 ISO 国家 / 地区选择、默认视野和可替换的 XYZ 底图地址。自有底图须兼容 Web Mercator XYZ 与 WGS84 地理坐标，不能直接混用 GCJ-02 / BD-09 偏移底图。
- **县级查询**：在地图输入“浙江省德清县”等地名，点击查找。经验证可返回正确的德清县坐标；同名地点会显示所属省市供选择。底图与地名数据由外部服务提供，详细覆盖、可用性与名称完整度取决于服务；不声称有全套离线县界数据库。
- **新建胶卷**：132 个内置常见 / 历史型号，可按 135 / 120、BW / Color、厂牌与型号、ISO、中文别名组合检索。支持 HP5PLUS / TMAX400 一类紧凑写法。未收录、分装或自己的命名可直接添加“自定义胶片”，保存到当前资料库，之后可检索。型号库不是“当前在售”清单，也不能保证穷尽全球所有历史小批次胶卷。
- **调试入口隐藏**：正常打开首页不显示实验菜单。使用 `http://127.0.0.1:8091/?debug=1`，或运行 `npm run serve -- --debug`（亦支持 `--demo` / `FILMALBUM_DEBUG=1`）才开启实验入口；生成演示数据仍需显式点击。
- **大图缩略图**：看片窗口底部展示当前筛选结果的缩略图与页码，支持翻页；点击缩略图替换当前看片 / 对比位置，保持筛选范围。
- **画册规格**：50 种预设，覆盖 A3–A6、B4–B6、常见英寸摄影画册、120–300 mm 方册、横版、长竖、2:1 / 2.5:1 / 3:1 全景与 16:9。卡片按实际尺寸比例绘制，显示毫米和宽高比；也可自定义 80–450 mm。
- **专业布局工具**：相对页面 / 安全边距 / 所选元素边界的左、右、上、下、水平及垂直居中；Shift 多选、等距分布、等宽 / 等高、锁定元素、图层前后、90° 旋转、1 mm 网格吸附、等比例缩放。方向键微移 1 mm，Shift 10 mm，Alt 0.1 mm；位置显示到 0.01 mm。改动均可撤销，自动保存避免异步覆盖本地新编辑。

## Studio 2.3.2：摄影编年时间轴

档案馆 → 时间轴使用独立的编年排版：左侧年份、右侧月份节点和紧凑横向卷卡，封面保持合理比例；宽屏可并排显示同月胶卷。卡片保留日期、地点、相机、型号、规格、编号、格数、状态与实物位置。单击检查档案，双击或右下角箭头打开整卷抽拉浏览。

“从近到远 / 从远到近”按拍摄日期在数据库排序后分页，不再使用胶卷创建编号排序。年份索引和计数仅对应当前已加载的一页；使用底部分页继续浏览，年份筛选仍可缩小整个资料库的查询范围。已知年份但月份不明的记录放入“月份未定”，完全无日期的放到“待定”组，两种排序都把无日期记录放到最后。选择“保存当前布局”可记住时间轴及排序偏好。

## 地图选卷与定位状态

“选择要定位的胶卷”可以按关键词、年份、135 / 120 / 220、BW / 彩色负片 / 反转 / 电影、具体型号、相机、镜头、日期范围、地点包含、项目和完整标签组合检索；可只看有照片的胶卷，按名称 / 日期 / 编号排序并分页。
